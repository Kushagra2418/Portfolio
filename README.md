Welcome to the repository for my personal 3D developer and analyst portfolio. This website is built using **React**, **TypeScript**, **Three.js / WebGL**, **GSAP**, and **Vite**, featuring an interactive 3D workstation scene, custom lighting, dark cosmic galaxy aesthetics, and project showcases reflecting my work in **AI Engineering, Data Science, and Business Analytics**.

---

## ✨ Key Features

- **Interactive 3D Workstation Experience:** WebGL and Three.js character model choreographed with GSAP ScrollTrigger cameras, realistic ambient lighting, and emissive screen glows.
- **Dark Cosmic Galaxy Theme:** Dynamic twinkling starfield canvas with nebulae, celestial particle systems, and glassmorphic UI cards.
- **Dual-Domain Interactive Skills Showcase:**
  - **✦ AI & Data Science:** Self-correcting RAG, autonomous multi-agent systems with LangGraph StateGraph, LLM fine-tuning (LoRA/SFT/DPO), FAISS vector search, PyTorch, and TensorFlow.
  - **📊 Analytics & Web:** Business intelligence, KPI dashboards with Power BI, SQL data modelling, FastAPI, React, Node.js, and Docker.
- **Pinned Horizontal Project Showcase:** Smooth, zero-dead-space project review with real-time `01`–`04` project navigation pills and direct repository links.
- **Interactive 3D Tech Stack Playground:** Real-time rigid-body physics simulation using `@react-three/rapier` featuring interactive technology spheres.
- **Verified Resume Downloads:** One-click download buttons in the contact section for both the **AI Engineer Resume** and **Business Analyst Resume**.

## 🛠️ Local Development & Setup

To run this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Kushagra2418/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
   The production-ready static assets will be output in the `dist/` directory.
